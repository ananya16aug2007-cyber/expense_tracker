# Personal Expense Tracker

## About the Project

This is a Python-based Personal Expense Tracker created to record and manage daily expenses.

The project allows the user to store details such as:
- Date of expense
- Amount
- Category
- Description

## Features

- Add a new expense
- View recorded expenses
- Search expenses by category
- Delete an expense
- Manage multiple expenses
- Display the total expenses
